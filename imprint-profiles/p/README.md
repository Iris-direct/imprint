# Publish your profile

First generate your card with the [imprint skill](../../skill/imprint/) (`/imprint` in Claude Code). Then get it on **[iris.direct/imprint-profiles](https://iris.direct/imprint-profiles)** one of two ways:

**Route A — Pull request (for developers).** Add one directory named exactly your GitHub login:

```
imprint-profiles/p/<your-github-login>/index.html
```

Open a PR to `Iris-direct/imprint`. After merge it appears in the gallery.

**Route B — Send it in (no git needed).** Send your `index.html` plus your GitHub / preferred handle to **Telegram [@to_be_king](https://t.me/to_be_king)** or **max@iris.direct** — it gets published for you, usually same day.

**One rule for both:** the page must pass imprint's privacy check — own projects by name only, client/NDA work anonymized, no secrets, no third-party personal data. Pages that violate this are sent back, not published.
