Get your profile on this page

First generate your card: install the imprint skill and run /imprint in Claude Code — it builds your page locally. Then publish it one of two ways:

route A · pull request

Open a PR

for developers
  1. Add your page at imprint-profiles/p/<your-github-login>/index.html
  2. Open a pull request to Iris-direct/imprint
  3. On merge it appears in the gallery below
route B · send it in

Send me your card

for everyone — no git needed
  1. Attach your index.html and your GitHub / preferred handle
  2. Send it to me — I publish it for you, usually same day
Telegram @to_be_king Email max@iris.direct

One rule for both routes: the page must pass imprint's privacy check — own projects by name only, client / NDA work anonymized, no secrets, no third-party personal data. Anything that doesn't is sent back, not published.
